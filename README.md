# SIGVRA Landing Page

Página estática pronta para GitHub Pages.

## Estrutura

- `index.html`
- `styles.css`
- `assets/sigvra-brand.jpg`
- `assets/favicon.svg`
- `.nojekyll`

## Antes da publicação

Edite o `index.html` para inserir:

- link oficial do Instagram;
- link oficial do TikTok;
- endereço de e-mail;
- link de contato;
- links futuros de `news` e `shop`.

## Publicação

Envie todos os arquivos e a pasta `assets` para a raiz do repositório.
Depois, em GitHub: `Settings → Pages → Deploy from a branch → main → / (root)`.
